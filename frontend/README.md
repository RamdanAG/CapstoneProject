# MyApp — Frontend (React + Vite + Tailwind)

## Setup
```bash
npm install
cp .env.example .env
npm run dev
```
Frontend jalan di http://localhost:5173
Pastikan backend jalan di port 3000 terlebih dahulu.

## Struktur
- `src/pages/` — halaman utama
- `src/components/` — komponen reusable
- `src/services/api.js` — axios instance
- `src/hooks/useFetch.js` — custom hook fetch data
